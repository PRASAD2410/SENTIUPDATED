## 1. Why The Graph Was Not Visible (Root Cause & Fix)

### Issue 1: Empty Database State (By Design)
* **What Happened:** In `backend/app/main.py`, the backend starts with an empty in-memory cache and empty MongoDB collections (`nodes: []`, `edges: []`).
* **Why it matters:** SentinelGraph relies on evidence intake. Until a file or investigative note is submitted via the **Input** tab (`/api/upload` or text intake), the graph has 0 nodes and 0 edges.
* **Fix:** Either upload files (e.g. CDR CSV, FIR PDF/TXT, bank records) in the frontend **Input** screen, or seed the demo data.

### Issue 2: Neo4j Host Resolution in Local vs. Docker Environment
* **What Happened:** In `.env`, `NEO4J_URI=bolt://neo4j:7687` is configured for container-to-container Docker networking. When running `uvicorn` directly on your Mac, `neo4j` cannot be resolved.
* **Fix:** When running locally outside Docker, set `NEO4J_URI=bolt://localhost:7687` in `.env`.

### Issue 3: Gemini Extractor Fallback
* **What Happened:** If `RELATIONSHIP_EXTRACTOR=gemini` is selected but the Gemini API key is missing or invalid, rule-based extraction should be active.
* **Fix:** Set `RELATIONSHIP_EXTRACTOR=regex` in `.env` for 100% offline, deterministic extraction, or provide a valid Gemini key.

## 3. What Makes This Solution Unique (Fascinating Hackathon Pitch Points)

When presenting to judges, highlight these 5 architectural pillars that separate SentinelGraph from generic RAG or graph toys:

```
┌───────────────────────────────────────────────────────────────────────────┐
│                      SENTINELGRAPH HACKATHON ADVANTAGES                   │
├──────────────────────────┬────────────────────────────────────────────────┤
│ 1. 100% Provenance       │ Zero hallucinated links. Every edge traces to  │
│    Guarantee             │ a character offset or CSV row in raw evidence. │
├──────────────────────────┼────────────────────────────────────────────────┤
│ 2. Dual-Engine           │ Deterministic SpaCy/Regex for speed & truth;   │
│    Hybrid AI             │ Gemini LLM only for semantic reasoning.        │
├──────────────────────────┼────────────────────────────────────────────────┤
│ 3. Multi-Modal Ingestion │ Auto-normalizes PDF, DOCX, CDR CSVs, Bank TXs, │
│                          │ and intelligence notes into unified entities.  │
├──────────────────────────┼────────────────────────────────────────────────┤
│ 4. Anti-Decoy Analytics  │ Distinguishes genuine criminal coordinators    │
│                          │ from innocent high-degree hubs (e.g. taxis).   │
├──────────────────────────┼────────────────────────────────────────────────┤
│ 5. Investigator-First UI │ Real-time Cytoscape graph with instant lead    │
│                          │ generation and zero-trust human-in-the-loop.   │
└──────────────────────────┴────────────────────────────────────────────────┘
```

1. **Deterministic Traceability (No "Black-Box" Magic):**
   * Most AI graph tools hallucinate connections. SentinelGraph strictly ties every node and relationship to an exact character span, line number, or table cell stored immutably in MongoDB GridFS.
2. **Hybrid Entity Intelligence (Rules + SpaCy + LLM):**
   * Core entities (Phone numbers, IMEIs, Bank Accounts, Vehicles) are parsed by strict regular expressions and validation checksums.
   * SpaCy handles Named Entity Recognition (Persons, Organizations, Locations).
   * Gemini is scoped strictly to finding hidden semantic relationships without being allowed to hallucinate entities.
3. **Multi-Source Fusion Across Disparate Domains:**
   * Automatically discovers cross-domain intersections between CDR (Call Detail Records), Banking (IMPS/UPI/NEFT), and unstructured FIR narratives.
4. **Graph Centrality & Bridge Discovery:**
   * Computes Betweenness Centrality, PageRank, and Degree distribution via NetworkX to detect criminal coordinators, money mule pass-throughs, and hidden broker nodes.
5. **Production-Grade Dual-Store Architecture:**
   * **MongoDB (GridFS + Document collections):** Durability, immutable evidence indexing, fast ingestion.
   * **Neo4j:** Graph traversal, Cypher querying, and multi-hop pattern matching.
